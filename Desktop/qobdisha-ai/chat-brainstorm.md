# Brainstorming Session: Qobdisha AI

- **User**: I want to build a digital memory and gifting platform called Qobdisha AI. Help me set the scope precisely.
- **AI**: Who are the primary users of this tool?
- **User**: Friends and family members who want to exchange digital time-capsule boxes containing memories, cards, and video greetings.
- **AI**: What format do the entries take?
- **User**: Text memories, greeting cards with custom senders, and video URLs.
- **AI**: Are the boxes public or private?
- **User**: Private, accessible via unique IDs generated when a box entry is created.
- **AI**: What actions can users perform?
- **User**: Add entries via REST API, list all items, search by keywords, and delete items.
